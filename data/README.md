# Datos locales

Esta carpeta guarda datos de entrada usados por el sistema CxC PHO.

- `private/`: archivos sensibles locales, no versionados.
- Formatos esperados: planillas `.xlsx` o `.csv`, documentos PDF y exportaciones internas.
- No subir RUT, montos reales, PDFs tributarios, credenciales, tokens ni respaldos de clientes.
- Si un archivo es necesario para pruebas compartidas, anonimizarlo antes de moverlo fuera de `private/`.
